Vectra Secure는 부산에서 AI와 소프트웨어를 만들고 운영하는 회사입니다. 보안 규정 때문에 외부 AI를 쓰지 못하던 기업도 AI를 업무에 쓸 수 있도록, 회사 데이터를 밖으로 내보내지 않는 AI를 만듭니다.

## 하는 일

AI 솔루션 개발, 소프트웨어 개발, 클라우드 인프라, 보안 내재화를 맡습니다. 기획부터 운영까지, 필요한 곳에서 함께합니다.

## 기술을 대하는 방식

**실제 문제에서 출발합니다.** 기술을 먼저 정하지 않습니다. 현장의 문제와 데이터를 살피고, 실제 업무에 도움이 되는 변화를 만듭니다. 결과는 근거와 검증으로 확인합니다.

**운영까지 책임집니다.** 만드는 순간보다 오래 쓰는 시간을 생각합니다. 보안과 유지보수를 설계에 담고, 고객의 팀이 직접 운영하고 확장할 수 있는 구조를 남깁니다.

**더 넓은 세상을 향합니다.** 서로 다른 환경에서도 신뢰할 수 있는 제품을 만들며, 글로벌로 나아갈 기반을 쌓습니다.
